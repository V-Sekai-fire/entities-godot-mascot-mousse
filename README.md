# entities-godot-mascot-mousse

An engine foundation's character mascot as a 3D scene file with its physically based textures.

## What it is for

It holds the model as its authors published it, with diffuse, normal and occlusion-roughness-metallic maps for each part.

## Build and run

Open `Mousse.blend` in a 3D modelling tool that reads `.blend` files.
